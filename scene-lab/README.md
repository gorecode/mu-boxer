# Стенд сюжетных сцен «Мести боксёра 2»

В стенде три сцены. По умолчанию открывается интро «Моё прошлое»: серьёзный рассказ Боксёра о событиях первой игры, 64,254 секунды, 17 закадровых реплик и 15 уникальных иллюстраций (для начала и финала разные выражения лица). «Вы пока посидите»: боксёр приходит за справкой, участковому звонят об избитом дворнике, следы бетона выдают посетителя. Длительность — 24 секунды, шесть реплик и девять монтажных кадров. «Только через мой труп» — бабка с сумкой в очереди, талон № 111 и самооправдание «Поэтому я был вынужден начать драку». Длительность — 27 секунд, шесть реплик и десять кадров. В конце этих двух сцен только экран предстоящего боя; боевой механики нет.

Статическое приложение на TypeScript и Vite. Без сервера, внешних шрифтов, аналитики, звуковых файлов и запросов к сторонним сервисам во время просмотра.

Публичный стенд: https://gorecode.github.io/mu-boxer/ . Исходники и workflow находятся в основном репозитории `gorecode/mu-boxer`.

## Запуск и проверки

Нужен Node.js 24 или новее. Все команды выполняются из `scene-lab/`.

```sh
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:browser
```

`check` запускает typecheck, ESLint, модульные тесты и сборку. Браузерные тесты отдельно запускают production preview с префиксом `/mu-boxer/`, чтобы проверить загрузку из подпапки Pages. На Linux, включая GitHub runner, используется установленный `/usr/bin/google-chrome`, если он есть; иначе нужен браузер Playwright. Workflow устанавливает Chromium только при отсутствии Chrome.

## Просмотр

- Сцена выбирается в монтажном листе. Переключение останавливает звук и сбрасывает позицию; скорость просмотра сохраняется. Прямые ссылки: интро `#scene=intro&t=0`, участковый `#scene=precinct&t=0`, бабка `#scene=queue&t=0`.
- Первый запуск — по кнопке: звук разрешается пользовательским жестом.
- Пробел — воспроизведение/пауза; стрелки — соседний кадр; R — сначала; M — звук; F — полный экран.
- Клавиши не перехватываются внутри кнопок, ссылок, ползунков и списков.
- Ползунок и монтажный лист переходят к нужному месту и ставят просмотр на паузу.
- Можно менять скорость, громкость и отключать звук. Звуковые эффекты сохраняют естественную высоту при изменении скорости просмотра.
- «Ссылка на этот момент» записывает сцену и время в адрес и пытается скопировать ссылку. Открытие ссылки не включает воспроизведение автоматически.
- При уходе на другую вкладку просмотр останавливается. Возобновление — вручную.
- Ошибка аудио не блокирует субтитры; ошибка загрузки иллюстрации блокирует запуск и объясняет причину.

## Добавление и настройка сцен

1. Положить иллюстрации в `public/art/`. Они попадут в сборку автоматически.
2. Описать объект `Scene` в `src/scenes.ts` либо импортировать его из отдельного файла рядом.
3. Передать его в `compileScene` и добавить в массив `scenes`. Выбор сцены и монтажный лист строятся из этого массива.

Необязательное `Scene.intro` задаёт `location` и `title` стартового экрана; без него используются подзаголовок и название сцены. Длительность берётся из кадров. Необязательное `Scene.hardCuts: true` отключает плавный зум между планами для монтажа с жёсткими склейками; настройка снимается при выборе другой сцены.

Поле `Scene.opponent` задаёт имя противника в форме после «против»: например, `Участкового`. Экран боя показывает «БОКСЁР ПРОТИВ УЧАСТКОВОГО».

Каждый кадр `Cue` задаёт:

- стабильный `id` и короткую монтажную метку `label`;
- `duration` в миллисекундах;
- `speaker` и полный текст `text` (пустой текст — намеренная пауза);
- необязательный `voice`: `boxer`, `officer`, `boxer-angry` или `grandma`;
- необязательный `speechDelay` в миллисекундах: выдержка изображения перед началом речи и печати текста. Во время этой выдержки субтитры скрыты; задержка входит в длительность кадра и учитывается при паузе, перемотке и смене скорости;
- необязательные `image` и `imageAlt` для смены иллюстрации; без них используется изображение сцены;
- `camera`: масштаб и точку привязки изображения в процентах;
- необязательные `shots`: планы внутри реплики с `at` в миллисекундах, `image`, `imageAlt`, `camera` и необязательным `cameraEnd`. Первый план начинается с нуля; следующие строго упорядочены и находятся внутри реплики. Камера плавно движется до `cameraEnd` за время плана; при reduced motion остаётся в начальной позиции. Смена картинки и движение не перезапускают речь; пауза, перемотка и скорость используют время сцены;
- необязательные `sounds`: название эффекта и задержку `at` от начала кадра;
- `fight: true` для экрана предстоящего боя.
- необязательный `setting` для короткой подписи времени и места; она скрывается до запуска и на титрах;
- необязательный `titleCard: { eyebrow, title }` для титра поверх рисунка, например в конце интро. Титр с пустым названием или одновременным `fight` отклоняется.

`compileScene` проверяет уникальность ID, длительности, кадрирование, попадание звуков в границы кадра и запас времени для реплики. Общие времена вычисляются автоматически. Проверяются также границы внутренних планов и оба положения камеры; все их иллюстрации входят в предварительную загрузку. Новые эффекты добавляются в тип `Sound` и `SceneAudio.play`.

Для участкового используются четыре иллюстрации: участковый до звонка, участковый с трубкой и два крупных плана боксёра — спокойное размышление и злость. Участковый явно повторяет примету «Ноги в бетоне?», затем идёт вставка ботинок. После «Вы пока посидите» боксёр на обычном лице произносит «Сесть?!?», затем выдерживает паузу. На границе секундного кадра — резкая смена на злое лицо с тем же кадрированием и низкий звуковой акцент, затем «Ещё раз я не собираюсь!». Все изображения выбранной сцены загружаются до разрешения запуска.

Для очереди подготовлены четыре новых рисунка: общий план с сумкой-преградой, бабка крупным планом, талон № 111 и боксёр, первым поднимающий кулаки. В размышлении используется существующий спокойный портрет боксёра. Бабка до финального экрана не атакует. Две внутренние реплики боксёра произносятся ровным голосом. Сигнал табло синтезируется отдельно; у бабки свой профиль голоса с более высокой основной частотой и формантой. Исходные PNG и промпты лежат в `assets/prototypes/queue-*-v1.*`, WebP для стенда — в `public/art/`. Рисунки созданы встроенным imagegen.

Интро реализует [утверждённую раскадровку](../INTRO_STORYBOARD.md) с уточнённой автором драматургией пауз: только голос Боксёра, без диалогов других персонажей и эпилога о справке. Все семь противников появляются в исходном порядке. Монтажный лист содержит 18 эпизодов: 17 коротких речевых мыслей и отдельное молчание суда с погашенными субтитрами. Внутри эпизодов 35 планов кадрирования, включая неподвижные выдержки в начале и конце движения.

Начало медленнее череды встреч. В эпизоде с оружием сначала устанавливается общий план, на «А пистолет…» начинается приближение, затем находка выдерживается крупно. Камера переходит к лицу в молчании и останавливается до «Как он туда попал…». Сохраняются сокращённые на 30% паузы, кроме точечно увеличенных выдержек раскрытых картин; скорость речи сохранена. После злого портрета — лицо Боксёра в переходе: во время «Но был вынужден» камера раскрывает поверженную девушку. Тот же приём используется с милиционером при побеге, Шофёром и Бандитом. На «я добрался» начинается отъезд без остановки реплики. На Байкере звучит «Каждый встречный», затем 0,570 с паузы. На девушке звучит «пытался мне помешать»: камера отъезжает из центра, общий план остаётся ещё 1,150 с. После побега общий план держится 2 с, после «Но был вынужден» — 1,5 с. После полной фразы о Бандите остаётся 1,9 с на рассматривание. Кадрирование Контролёра сохранено. В финале Боксёр сосредоточен на груше; камера раскрывает зал и останавливается. Длительности и движения поставлены отдельно от длины речи; скорость произнесения слогов осталась прежней. Ползунок позволяет отсматривать внутренние планы.

Эталон лица — `assets/prototypes/boxer-thinking-v1.png` из сцены участкового; злой портрет `boxer-angry.webp` используется непосредственно. Одиннадцать новых иллюстраций созданы встроенным imagegen с этим референсом: `assets/prototypes/intro-*-v3.png`, рядом сохранены промпты. В тюремном кадре дополнительной правкой убрана ошибочная форма Авторитета; финальный рисунок сохранён как `intro-cell-v3.png`. Существующие `intro-arrest.webp` и `intro-court-v2.webp` сохранены по выбору автора. Остальные новые кадры воссоздают согласованные события и детали оригинала, а не выдают себя за извлечённые игровые скриншоты. Пять уточнённых рисунков и промптов — `assets/prototypes/intro-*-v4.*`: указатель направлен к Москве, телефон обращён экраном к щеке, в переходе и при побеге видно лицо Боксёра, финальный взгляд направлен на грушу. Лицо побега дополнительно исправлено прямым референсом участкового: `intro-escape-v6.png` и промпт рядом, runtime — `intro-escape-v6.webp`. В этой версии уменьшена голова и уточнён хват за ограду; длительности сохранены. Начальный портрет в зале сохранён. WebP для стенда — `public/art/intro-*-v3.webp` и `intro-*-v4.webp`. [Тайминги реализации](../INTRO_SCENARIO.md).

Субтитры и «му-озвучка» используют общий план речи: примерно 180 мс на слог, дополнительные паузы на знаках препинания и 100 мс перед началом. Это настраиваемая стилизация темпа речи. `speech.ts` задаёт ритм, раскрытие текста, ударения и мелодию; `moo.ts` синтезирует звук. Основой послужил гармонический генератор и формантные фильтры [mu-screamo](https://github.com/enikey87/mu-screamo), адаптированные без зависимости от его игрового движка. Высота источника меняется непосредственно; форманты остаются независимыми от неё. Вопросы получают восходящую интонацию, окончания утверждений — нисходящую. Участковый ниже по тону, у злого боксёра выше тон и больше хрипа.

Пауза, перемотка и выключение звука отменяют текущую реплику. При продолжении или изменении скорости озвучивается оставшийся фрагмент; история реплики не проигрывается заново. Скорость меняет ритм, сохраняя высоту голоса.

## Устройство

- `scene.ts` — формат сцен, проверка и ссылки на момент.
- `scenes.ts` — сцена участкового и реестр сцен.
- `queue-scene.ts` — утверждённый сюжет сцены с бабкой и его тайминги.
- `intro-scene.ts` — утверждённый рассказ о прошлом, драматические выдержки и независимая постановка камеры.
- `timeline.ts` — часы просмотра без DOM и аудио; пропущенные звуки не проигрываются при перемотке.
- `speech.ts` — единый план печати субтитров и озвучки, интонационные кривые.
- `moo.ts` — процедурный голос: гармоники, дыхание, форманты и лёгкий перегруз.
- `audio.ts` — управление голосом и синтез Web Audio: фон вентилятора, звонок, трубка, бумага, стул и низкий акцент. Звуки останавливаются при паузе и перемотке.
- `main.ts` — DOM, управление и привязка к браузеру.
- `style.css` — адаптивный экран 4:3 и отдельная панель отсмотра; учтён reduced motion.
- `tests/` — границы времени, переходы, валидация, ссылки, браузерные ошибки, адаптивность и реальный выходной сигнал Web Audio через AnalyserNode и OfflineAudioContext (сигнал, паузы, высота, клиппинг и отмена речи).

Автотесты Chrome не доказывают совместимость с реальными iPhone или качество звучания на физических динамиках.

При установке 18 ноября 2026 года `npm audit` сообщил о [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) в транзитивном `picomatch` инструментов разработки. На эту дату исправленной версии нет. У опубликованного приложения нет runtime-зависимостей; введённые посетителем glob-шаблоны не обрабатываются. После выпуска upstream-исправления нужно обновить lockfile и повторить проверки.

## Публикация

Workflow `.github/workflows/pages.yml` сначала запускает проверки и браузерные тесты. Только успешный `main` публикует `scene-lab/dist` в Pages. В настройках репозитория источник Pages — GitHub Actions. Относительный `base: './'` позволяет разместить приложение в подпапке любого репозитория. Исходные Markdown-документы за пределами `dist` не входят в артефакт сайта.

Изменения сцены публикуются обычным push в `main`. Для отката нужно вернуть соответствующие изменения новым коммитом и дождаться успешного workflow.
